Tether workspace mockups

Clickable proposal with sample data. No live terminal connection.

Try opening a session, returning home, and switching to Files.

Home → Sessions → terminal. Open tabs come first. Existing tmux sessions expand to their windows; each window opens as one tab. Closing a tab never kills tmux.

Phone dock. At rest, one row holds the active-tab chip, line field, and keyboard toggle. With the keyboard up, the scrolling key row sits above it. The tab chip opens Sessions: open-tab pills, host sessions and windows, plus search and New session. ctrl and alt arm the next key; ← → come from a long-press drag on the terminal, not keys.
