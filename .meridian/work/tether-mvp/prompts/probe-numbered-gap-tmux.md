1. Without tether: start a private server (tmux -L <your-spawn-id> -f /dev/null), attach a plain control client (tmux -C, stdout to a file, reading as fast as possible; then a deliberately slow reader), flood numbered lines in a pane the same way the test does (see NUMBERED near tests/tmux_real.rs:595, and whether the test takes snapshots/capture-pane concurrently: reproduce that too if the plain flood doesn't fail). 2. When a line is missing from control output, is it in the pane's own history (capture-pane -S - -E -)? Set history-limit large enough. Present in history but absent from %output means tmux's control-mode path dropped it; absent from both means the loss is before the grid (pty/source).
