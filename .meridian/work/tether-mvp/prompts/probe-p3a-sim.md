P3a (phone dock) is built uncommitted in the working tree; its author could not raise the keyboard in the Simulator (no touch injection). An earlier probe (p108) drove a Simulator app with a throwaway XCTest UI-test target; do the same against Mobile Safari (`XCUIApplication(bundleIdentifier: "com.apple.mobilesafari")`).
Setup: build the web client from the working tree and run the daemon from the working tree (release or debug) against an isolated tmux (`/tmp/tether-meridian-501/tmux/3.4/bin/tmux`, `-L p3asim`), reachable from the Simulator (the Simulator shares the Mac's network; use the dev/harness serving path the e2e suite uses for real daemons — see web/e2e/dock/dock.real.ts and web/playwright.config.ts).
