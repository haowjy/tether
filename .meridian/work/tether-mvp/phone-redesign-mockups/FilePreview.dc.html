tether

Phone-first client for tmux on a dev server, over Tailscale. A Rust daemon bridges tmux control mode to a native iOS app.

Build from source

scripts/preflight.sh full
cargo run -- --version

Then run tether setup and follow docs/setup.md.

How it fits

iPhone app↓ HTTPS + WebSocket tether daemon↓ tmux -C your tmux Mermaid, rendered (pinch to zoom, drag to pan)
